# 第一部分：工作模式（标准流程 SOP）

> 这是本项目验证过的协作模式：用户出想法，AI 负责问清、调研、给方案、写码、测试、发版。
> 核心原则：**细节问不完不动手；动手必测试；测试必记录；每版必备份。**

## 第 0 步 · 接手项目（新会话必做）

先读三样东西掌握现状（顺序固定）：
1. `新会话启动提示词.md`（交接总纲）
2. `docs/更新日志.md`（版本履历，以它为准）
3. 最新版开发副本的头部注释与本文件

## 第 1 步 · 用户提出要求

用户可能是模糊的一句话（"我想要一个时间条"），也可能是明确指令。AI 的任务是把它变成可实现的方案，**不许跳过提问直接写码**。

## 第 2 步 · 先问大致功能

用大白话复述理解："你想要的是不是 XXX？"——先对齐**做什么**，再谈怎么做。排除误解只花一分钟，写错方向要返工一整天。

## 第 3 步 · 逐功能详细追问需求（颗粒度到数值）

对每个确认的大功能，把细节问到能写代码的程度：
- **数值**：上限/下限/步进/概率（例：好感单次加多少、扣多少、保护线在哪）
- **边界情况**：忘了上报怎么办？AI 乱填怎么办？数据倒流怎么办？（每个都要"保底行为"）
- **显示与交互**：放在哪？长什么样？手机端能用吗？
- **与现有功能的关系**：替换旧的还是叠加？旧的保不保留兼容？
- **成本**：API 每轮多花多少？延迟多少用户能接受？

**如果用户提到"类似某个东西"（比如"像酒馆的 MVU"）→ 先去 GitHub 搜索**有没有现成项目/类似实现，回报三件事：有没有、核心机制是什么、能不能借鉴（注意许可证，GPL 不能抄代码只能借鉴思路）。

## 第 4 步 · 给方案（全部了解后才做）

- 给出 **2~3 个实现方案**，每个说清：技术路线（用什么机制/数据结构/语言特性）、优点、缺点、风险
- 全部用**大白话**（用户不是程序员），配对照表或示意图
- 明确给出**推荐**和理由
- 等用户拍板，**用户没说"动手"就不写一行代码**

## 第 5 步 · 导出制作日志

方案确认后，把实现细节整理成文档（写进仓库 `docs/` 或本地测试夹具），内容包括：数据结构、函数清单、注入/解析格式、兜底链、测试要点。标准：**其他 AI 模型拿到这份日志能独立写出同样的代码**。本项目已积累：`docs/更新日志.md`（每版实现要点）+ 各版 `test/devlog-*.md`。

## 第 6 步 · 写代码 → 立即测试

- 每个功能一轮：写完 → 语法检查 → `node build.js && node combined.cjs`（单元断言）→ 真实卡联调（cardharness，见 `测试夹具/`）
- **失败就修，修复必须写进 devlog**（错误现象 + 原因 + 修法）
- 随机性断言连跑 3 轮确认稳定
- 真实卡测试用副本（不碰用户真实存档），密钥放仓库外

## 第 7 步 · 发版上传

- 测试全过 → **问用户是否上传**（奈亚项目默认上传）
- 升版本号（末位小改/中位大改末位归零/首位重构）→ 全量替换版本串 → 重命名文件 → 备份旧版到 `插件\备份\`
- 覆盖 `Nailya.plugin.js` → git commit（"v<版本>: 摘要"）→ 打 tag → push → git fetch 验证
- 更新 `docs/更新日志.md` + devlog + 会话摘要/记忆文件

## 错误与修正全记录（14 起，全部当场修复）

1. **forEach 里用 continue**（非法语法）→ 改 return
2. **python heredoc 转义事故 ×4**（\n、\u4e00、\s 被解码成真实字符/丢失）→ 教训：复杂补丁一律写成 .py 文件（放测试夹具目录），字符串用 chr() 构造，不用内联 heredoc
3. **String.replace 替换串含 $' 序列**被展开，卡数据被拦腰截断 → 必须用函数替换 `replace(re, () => ...)`
4. **测试提前引用未声明变量**（TDZ）且异常中断导致开关未复位污染后续测试 → 直接用 __captured.replacers[0]
5. **变量名混用**（runDeepSeekAccounting 里 report/assetReport）→ ReferenceError 被兜底 catch 吞掉难察觉 → 改名；教训：兜底 catch 里要 console.log
6. **设计缺口：新模式无 Vis 标签时选图无处落地** → 补 deepPickMap 选图追加逻辑
7. **瘦身门控引用未定义变量** legacyPromptMode → 补定义
8. **测试断言预期写错**（保护线是"0.5递减到线"不是"立即钳制"）→ 修预期
9. **find('];') 命中 JSON 文本值内部**的过早匹配 → 嵌入库替换改用后锚点（const ALL_SEMANTIC_WORDS）
10. **json.dumps 数组自带结尾 ']' 被再追加 '];'** → 双重闭合 → 确定性截尾（从尾跳过 ]; 停在 } 再接 '];'）
11. **vm 探针误报**（把结尾 ';' 包进括号）→ 修探针
12. **死代码连带暴露**：删死函数后其内部调用的函数变孤儿 → 扫描-删除-重扫循环直至归零
13. **扫描脚本 bash -e 转义错误** → 改写脚本文件
14. **sed 处理含反斜杠行翻车** → 一律 python 处理
