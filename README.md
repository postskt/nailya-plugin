# Nailya · 奈亚（RisuAI 插件）

[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](./LICENSE)

奈亚是一个 RisuAI Plugin API v3.0 插件，为成人向角色扮演提供一套完整的状态模拟与视觉注入引擎。

> ⚠️ 本插件为成人向角色扮演辅助工具，仅供成年人使用。

## 功能一览

- **好感度系统**：好感度阶段与好感度墙，随剧情推进注入状态指令
- **生理模拟**：生理周期 / 怀孕 / 产后模拟
- **穿搭注入**：八部位穿搭状态注入
- **图包选图**：图包人名前缀识别 + 中文触发词自动选图
- **酒馆预设接管**：接管 SillyTavern 风格预设
- **全量备份**：档案数据一键备份

## 安装

1. 下载本仓库的 [`Nailya.plugin.js`](./Nailya.plugin.js)（右键另存为，文件名随意）；
2. RisuAI → 插件设置 → 导入插件；
3. **导入/启用时会弹两个权限确认框，必须都选"允许"**：
   - 访问数据库（用于读角色卡/图包/模块）
   - **替换聊天内容（replacer）**——不授权这个，好感/时间/视觉指令全部发不出去；
4. 打开插件面板 → 顶部「AI接口」填入你自己的 API Key → 对每张要玩的卡点「一键AI分析」建档。

> **重要**：奈亚的所有功能（顶部时间注入、视觉标签、好感墙、自动选图）都依赖"当前卡已建档"。没建档 = 功能全部静默不启动。面板上的「注入」按钮和「图包与索引 → 注入预览」可以随时检查注入是否真的生效。

## 更新

- `//@update-url` 已配置指向本仓库，RisuAI 会自动检查新版本；
- 手动更新：下载新的 `Nailya.plugin.js` → 插件设置里删除旧版 → 导入新版 → 刷新页面 → **重新确认权限**。

## 多设备（手机浏览器）注意

- 电脑与手机浏览器是**独立环境**：插件需要各自导入，**权限需要各自授权**；
- 若使用同一账号云存档，插件与档案数据会同步，但权限框仍会在新设备上重新弹一次；
- 每张卡都要各自建档。

## 已知共存冲突

`char_manager`（角色卡管理器）与本插件功能高度重叠（好感/时间/怀孕引擎各一套），同时启用会导致 AI 收到两套互相冲突的状态指令。**二选一**。
