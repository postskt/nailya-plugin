# V7.1.0 开发日志（日程/记忆/场外事件/NPC）

## 实现内容
- 真实历法：星期几（历元2000-01-01=周一，30天制）进 topNote 与状态卡
- 日程查询：优先用户导入的日程模板（4~12小时块带地点），无模板时用 AI 记账每轮填报的 whereabouts；状态卡新增"她现在: 活动·地点｜星期"
- 记忆系统：每角色独立列表（天然防全知），AI 记账每轮回传 memoryNotes（只记重要事，weight 1~5），召回=权重优先 top6 注入状态卡；女主配额200、NPC 25；🧠记忆管理入口支持增删清
- 场外事件：跨天时 AI 生成（1天1条/周2/月3/年4），重大事件 5%/天 major=true → 写入记忆(weight5) + 性格外围演变 growthNotes（面板可见，防 OOC 靠核心锁死+演变留痕）
- NPC 体系：👥NPC 按钮粘贴 NPC 简档 JSON（支持数组批量）；NPC 独立存储（fpm_npc_v1）；记账对 NPC 分账好感/情绪/记忆（配额减半）；NPC 状态行进记账 prompt
